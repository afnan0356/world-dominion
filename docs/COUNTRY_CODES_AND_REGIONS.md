# Country codes and picker regions

Generated by `python3 tools/build_country_codes.py`. Do not edit by hand: CI runs
it with `--check` and fails when this file is stale.

Both tables come from the **same pinned Natural Earth file** the map is drawn
from. No code and no group was typed from memory, and neither was chosen by
hand for a single record.

## Country codes

| Status | Records | Meaning |
| --- | ---: | --- |
| `iso-official` | 236 | the record's own officially assigned ISO 3166-1 code |
| `user-assigned` | 1 | a widely used code that is not officially assigned |
| `none` | 5 | the source has no code of this record's own; nothing is invented |

### What was wrong, and what the source itself fixed

Natural Earth writes `-99` where it has no code, and Taiwan's two-letter field
holds `CN-TW`, which is not a two-letter code. The same file carries corrected
fields (`ISO_A2_EH` / `ISO_A3_EH`), and those are the values adopted here:

| Record | Name | Before | After | From | Status |
| --- | --- | --- | --- | --- | --- |
| `ATC` | ATC | — | — / — | — | `none` |
| `CYN` | CYN | — | — / — | — | `none` |
| `FRA` | FRA | — | FR / FRA | `ISO_A2_EH`, `ISO_A3_EH` | `iso-official` |
| `IOA` | IOA | — | — / — | — | `none` |
| `KAS` | KAS | — | — / — | — | `none` |
| `KOS` | KOS | — | XK / — | `ISO_A2_EH` | `user-assigned` |
| `NOR` | NOR | — | NO / NOR | `ISO_A2_EH`, `ISO_A3_EH` | `iso-official` |
| `SOL` | SOL | — | — / — | — | `none` |
| `TWN` | TWN | — | TW / TWN | `ISO_A3`, `ISO_A2_EH` | `iso-official` |

The two records that the corrected field would have given their **administering
state's** code (the Indian Ocean Territories and Ashmore and Cartier Islands) are
left without one: three records answering to `AU` would be wrong, and copying a
parent's code onto a territory is a sovereignty claim this project does not make.

error rather than a silent default.
