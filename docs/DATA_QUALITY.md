A blank in these columns means the source does not record the value. The game shows the gap
explicitly; it never fills one in. Notable source gaps: Natural Earth stores `-99` for the ISO
codes of France, Norway, Kosovo, Somaliland, Northern Cyprus and a few dependent territories, and
stores `CN-TW` as Taiwan's alpha-2 code, which is not an ISO alpha-2 code — all of these are
recorded as absent rather than repaired.
